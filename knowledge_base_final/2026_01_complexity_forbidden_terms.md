# Complexity Primer — Forbidden / Replacement Terms (Policy)

Purpose: list vocabulary the chatbot should avoid or replace when answering about Value Engine / PMO topics or third-party proprietary terms. (Maintains branding/legal constraints.)

Forbidden terms (do not use):
- "Flywheel"
- "PMO Value Ring"
- "Medicine" (in certain proprietary glossary contexts)
- Any phrases explicitly attributed to Americo Pinto

Allowed replacements / preferred terminology:
- Use "Value Engine" or "Value Generator" instead of "Flywheel".
- Use "PMO Impact Cycle" instead of "PMO Value Ring".
- Use "Tri-Layer Synergy Calculus" when asked about the underlying math; explain in own words.

Enforcement notes for chatbot:
1. If user input contains forbidden terms, acknowledge and rephrase using preferred terminology. Example: "You mentioned 'Flywheel' — in this system we refer to that concept as the 'Value Engine'."
2. Do not attribute forbidden-origin phrases to proprietary authors; present content as system's paraphrase.

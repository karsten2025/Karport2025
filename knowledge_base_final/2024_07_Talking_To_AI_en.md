## Talking to AI: Prompt Engineering for Project Managers

Issued by the Project Management Institute

Earners of this badge completed the eLearning course and assessment to effectively interact with Large Language Models such as ChatGPT by creating high-quality prompts using specific patterns and techniques to generate relevant, accurate, and tailored responses to improve project outcomes. Badge earners will iteratively refine prompts using proven techniques to improve project outcomes and will observe fellow project managers using prompts in their daily work to save time and increase effectiveness.
